## 三、开发计划

### 技术架构

```
前端:     uni-app (Vue3 + TypeScript + Pinia)
后端:     Java 17 + Spring Boot 3 + MyBatis-Plus
数据库:   MySQL 8.0 + Redis
部署:     微信云托管
存储:     腾讯云COS（图片/视频/课程）
后台:     Vue3 + Element Plus
```

### 产品形态

```
两类商品：
  A. 实物商品（农副产品+保健品）→ 下单→付款→发货→物流→收货→评价
  B. 虚拟商品（课程研学）→ 下单→付款→自动发货→解锁课程内容
```

### 数据库核心表设计（第一期）

```
用户相关（5张）
├── user                 -- 用户基本信息
├── user_address         -- 收货地址
├── user_member          -- 会员信息（等级/到期时间）
├── user_favorite        -- 收藏
└── user_footprint       -- 浏览足迹

商品相关（6张）
├── category             -- 商品分类（二级树）
├── product              -- 商品SPU（type字段区分实物/虚拟）
├── product_sku          -- 商品SKU
├── product_image        -- 商品图片
├── course               -- 课程信息（章节/视频地址）
└── course_progress      -- 用户学习进度

交易相关（6张）
├── cart                 -- 购物车
├── order                -- 订单主表
├── order_item           -- 订单商品明细
├── order_logistics      -- 物流信息
├── payment              -- 支付记录
└── refund               -- 退款/售后记录

营销相关（3张）
├── coupon               -- 优惠券模板
├── user_coupon          -- 用户优惠券
└── member_plan          -- 会员套餐（月卡/年卡价格/权益）

运营相关（4张）
├── banner               -- 轮播图
├── notice               -- 公告
├── message              -- 用户消息
└── feedback             -- 意见反馈

系统相关（4张）
├── admin_user           -- 后台管理员
├── admin_role           -- 角色
├── admin_permission     -- 权限
├── system_config        -- 系统配置
└── freight_template     -- 运费模板

总计：约28张表
```
