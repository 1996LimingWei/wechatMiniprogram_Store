# v1.0 小程序提审与真机回归清单

> 本清单用于微信体验版、正式版提审前验收。客户资料未提供前，只能完成代码准备和内部自测，不能标记真实提审完成。

## 一、客户资料

- [ ] 客户正式小程序 AppID 已写入 `shop-miniapp/manifest.json` 与 `shop-miniapp/project.config.json`。
- [ ] 服务器域名已加入微信后台 request 合法域名。
- [ ] 上传域名已加入微信后台 uploadFile 合法域名。
- [ ] 下载域名已加入微信后台 downloadFile 合法域名。
- [ ] 微信后台隐私保护指引已按本项目收集字段完成配置。
- [ ] 客服能力已在微信后台开通，并确认 `open-type="contact"` 可进入会话。

## 二、版本配置

- [ ] 体验版构建前设置 `VUE_APP_API_BASE_URL=https://staging.example.com/`。
- [ ] 正式版构建前设置 `VUE_APP_API_BASE_URL=https://api.example.com/`。
- [ ] 正式版构建不包含本地地址、测试地址或 Mock 支付入口。
- [ ] `manifest.json` 中 `mp-weixin.__usePrivacyCheck__` 为 `true`。
- [ ] `project.config.json` 中 `setting.urlCheck` 为 `true`。

## 三、页面入口

- [x] 隐私政策入口存在。
- [x] 用户协议入口存在。
- [x] 售后政策入口存在。
- [x] 在线客服入口存在。
- [x] 账号注销说明存在。
- [x] 生产环境收到 `mockPay=true` 时不会打开模拟支付。

- [ ] 小程序名称、类目、头像、简介和服务范围与客户主体一致。

- [ ] 至少保存 iOS 和 Android 核心链路截图。
