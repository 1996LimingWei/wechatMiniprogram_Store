# v1.0 客户验收清单

## 1. 环境验收

- [ ] 正式域名 HTTPS 可访问。
- [ ] 后端健康检查正常。
- [ ] 管理后台可登录。
- [ ] 小程序体验版可访问。
- [ ] 生产配置未启用 Mock 支付、Mock 退款、Mock 物流。

## 2. 交易验收

- [ ] 用户登录成功。
- [ ] 商品列表展示真实商品。
- [ ] 商品详情图片正常。
- [ ] 加入购物车成功。
- [ ] 下单金额正确。
- [ ] 微信支付成功。
- [ ] 后台发货成功。
- [ ] 小程序物流查询成功。
- [ ] 用户申请售后成功。
- [ ] 后台同意退款成功。
- [ ] 微信退款到账。

## 3. 运营验收

- [ ] 后台上传素材成功。
- [ ] 后台新建商品成功。
- [ ] 后台导入商品成功。
- [ ] 后台导出商品成功。
- [ ] 后台批量上下架成功。
- [ ] 库存工作台可查询。
- [ ] 库存流水可追溯。
- [ ] 运费规则生效。
- [ ] 订单导出可用。
- [ ] 批量发货可用。

## 4. 财务验收

- [ ] 支付单可查询。
- [ ] 支付异常可同步。
- [ ] 退款单可查询。
- [ ] 退款异常可同步。
- [ ] 日终对账可生成。
- [ ] 对账差异可标记处理。
- [ ] 对账结果可导出。

## 5. 权限验收

- [ ] 商品运营不能进入财务对账。
- [ ] 客服不能修改商品价格。
- [ ] 财务不能发货。
- [ ] 只读账号不能写操作。
- [ ] 高风险操作进入审计日志。
