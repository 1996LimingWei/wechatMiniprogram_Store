# v1.0 运维手册

## 1. 每日检查

- 检查后端健康状态。
- 检查 MySQL 与 Redis 容器状态。
- 检查支付异常列表。
- 检查退款异常列表。
- 检查日终对账差异。
- 检查备份文件是否生成。

## 2. 备份策略

- MySQL 每日至少备份一次。
- 备份文件保留不少于 7 天。
- 生产恢复前必须先恢复到测试库验证。
- 微信支付证书、平台证书、HTTPS 私钥不进入数据库备份。

## 3. 告警联系人

上线前由客户提供：

- 业务负责人。
- 财务负责人。
- 技术运维负责人。
- 微信商户平台协作人。

## 4. 高风险操作

以下操作必须由具备权限的账号执行，并保留审计：

- 修改商品价格。
- 批量调整库存。
- 修改运费规则。
- 发货和批量发货。
- 售后同意退款。
- 人工同步支付。
- 人工同步退款。
- 标记对账差异。
- 导出订单。
- 导出对账。
