# v1.0 生产部署与回滚手册

## 1. 前置条件

- 服务器已安装 Docker 与 Docker Compose。
- 正式域名已备案并解析到服务器。
- HTTPS 证书已准备为 `fullchain.pem` 与 `privkey.pem`。
- 客户已提供微信小程序、微信支付、快递 100 和对象存储资料。
- 数据库初始管理员默认密码已替换，生产禁止使用 `admin123`。

## 2. 目录准备

```powershell
Copy-Item .env.prod.example .env.prod
New-Item -ItemType Directory -Force deploy/secrets/tls
New-Item -ItemType Directory -Force deploy/secrets/wechat-pay
New-Item -ItemType Directory -Force deploy/backups/mysql
New-Item -ItemType Directory -Force deploy/logs/backend
New-Item -ItemType Directory -Force deploy/logs/nginx
```

将证书放入：

- `deploy/secrets/tls/fullchain.pem`
- `deploy/secrets/tls/privkey.pem`
- `deploy/secrets/wechat-pay/apiclient_key.pem`
- `deploy/secrets/wechat-pay/platform_cert.pem`

然后填写 `.env.prod`。该文件禁止提交。

## 3. 发布步骤

```powershell
.\scripts\verify-secret-scan.ps1
.\scripts\verify-production-config.ps1

docker compose --env-file .env.prod -f docker-compose.prod.yml build
docker compose --env-file .env.prod -f docker-compose.prod.yml up -d
docker compose --env-file .env.prod -f docker-compose.prod.yml ps
```

后端健康检查：

```powershell
Invoke-RestMethod https://<正式域名>/healthz
docker compose --env-file .env.prod -f docker-compose.prod.yml exec backend wget -q -O - http://127.0.0.1:8085/actuator/health
```

## 4. 数据库迁移

生产启动会校验数据库已执行必需迁移。发布前先备份，再执行迁移：

```powershell
.\scripts\backup-mysql.ps1 -EnvFile .env.prod
.\scripts\migrate-db.ps1 -Database shop -MysqlContainer <mysql-container> -MysqlUser root -MysqlPassword <root-password>
```

如果迁移不可回滚，必须在发布记录中写明前向修复方案。

## 5. 回滚步骤

应用回滚：

```powershell
docker compose --env-file .env.prod -f docker-compose.prod.yml down
git checkout <上一稳定版本>
docker compose --env-file .env.prod -f docker-compose.prod.yml build
docker compose --env-file .env.prod -f docker-compose.prod.yml up -d
```

数据库回滚原则：

- 优先使用前向修复迁移。
- 如必须恢复备份，先恢复到测试库验证，再窗口期恢复生产。
- 恢复后必须执行完整交易流和对账脚本。

## 6. 日志与排障

- 后端日志目录：`deploy/logs/backend`
- Nginx 日志目录：`deploy/logs/nginx`
- 业务排障优先使用订单号、支付单号、退款单号、售后单号。

## 7. 发布验收

- 后端健康检查为 `UP`。
- 管理后台可登录。
- 小程序体验版可访问正式 API。
- 真实小额支付成功。
- 真实小额退款成功。
- 快递 100 真实轨迹可查询。
- 日终对账可以生成。
