# 管理后台列表横向拖动条可用性规格

## 目标

让非技术操作员在窄屏或字段较多的列表中，稳定、清晰地横向查看内容，不把横向滚动误解为缩放整张表。

## 规则

- 表格外框始终占满其父容器且宽度稳定；横向拖动只能移动表格内部列内容。
- 表格列宽超出可用宽度时，使用浏览器和系统的原生横向滚动条。显示位置留在表格内容下方，不覆盖末行。
- 当前宽度能放下全部列时，隐藏横向滚动条。
- 拖动时表头与表体同步，松开后保留滚动位置。导航与普通内容区沿用既有滚动行为。

## 验收标准

- 覆盖商品列表、SKU 规格、库存工作台及流水，以及内容、交易、会员、营销和系统管理表格。
- 在宽屏没有横向溢出时看不到滚动条，窄屏溢出时能滚动查看右侧列，最后一行的图片与操作按钮完整显示。
