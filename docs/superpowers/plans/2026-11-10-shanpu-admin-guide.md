## 2026-11-17 首轮主流程验收

使用同一套验收后台和小程序，准备一个商品运营账号、一个可修改的验收商品和一张可发布的测试 Banner。单验后台与小程序展示时不需要下单。正式或体验环境先确认后台前后端已部署包含本轮修复的版本。

| 顺序 | 操作 | 通过条件 |
| --- | --- | --- |
| 1. 登录 | 从登录页用默认「商品运营」角色登录。若需要复验长密码，用管理员在验收环境新建一个密码超过 18 位且不超过 72 个 UTF-8 字节的测试账号，再从登录页进入。 | 有权限的账号直接进入商品列表，不跳 403；启用的测试账号可以用同一个密码登录。 |
| 2. 改商品并读回 | 商品管理 → 商品列表 → 搜索验收商品 → 编辑。改名称、主图、详情和规格售价，保存后退出再打开。另用一条预先准备的无 SKU 旧商品，只改名称并保存。 | 保存后的名称、图片、详情和各规格价格一致；旧商品不因缺规格而拒绝保存，生成默认规格并保留原售价、库存。 |
| 3. 调库存并上架 | 商品管理 → 库存工作台，选同一规格，分别加 4 件、减 2 件并填写原因，打开「流水」；再从商品列表上架验收商品。 | 库存净增 2 件；两笔流水的方向、数量、原因正确，查询不报错。商品状态显示已上架。 |
| 4. 发布首页 | 可视化装修 → 实时预览与编辑，替换测试 Banner 图片并把跳转目标指向验收商品，点击「检查并发布」→「确认发布」。另用一个仅有商品查看权限、没有内容查看权限的账号核对入口。 | 有商品和内容查看权限的账号能加载预览，具备内容维护权限时可以发布；缺少内容查看权限的账号不显示入口，直接访问也会被限制。 |
