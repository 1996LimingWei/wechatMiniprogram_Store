# 生产交易闭环收尾计划

## 目标

在现有微信支付回调和生产配置基础上，关闭仍可绕过支付的会员入口，补齐支付主动查单、真实微信退款、售后失败恢复和管理后台生产代理。

## 实施范围

1. 黄金会员体验开通仅允许开发环境显式开启，生产环境返回不可购买状态，小程序不再展示可直接开通按钮和未落地权益承诺。
2. 微信支付增加商户订单主动查询、查询节流和定时对账，回调丢失时可按微信最终状态补记支付成功。
3. 退款 Provider 增加失败终态并实现微信退款提交/查询；售后拒绝、撤销或退款失败后允许重新申请。
4. 管理后台 Nginx 镜像增加 `/admin-api/` 反向代理、静态缓存和健康检查。
5. 同步数据库迁移、自动化测试和状态文档。

## 验证

- 后端聚合测试通过。
- 管理后台类型检查和生产构建通过。
- 小程序脚本语法、路由和开发入口扫描通过。
- 数据库迁移在 Docker 可用时执行隔离库验证；不可用时明确记录限制。
