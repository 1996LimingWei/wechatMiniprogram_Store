# 管理后台订单与售后管理实施计划

## 目标

完成 Issue #4 订单管理与 Issue #5 售后管理，使运营人员可在 `shop-admin` 中查询订单、查看详情、发货、查看物流，并处理退款申请。

## 订单管理

1. 订单列表支持全部、待发货、待收货、已完成、已取消、退款中状态切换。
2. 支持订单号精确搜索和下单时间范围筛选。
3. 表格展示订单号、用户信息、商品摘要、实付金额、状态与下单时间。
4. 订单详情展示基础信息、收货地址、商品明细、金额汇总、支付信息和订单日志时间线。
5. 仅待发货订单显示发货操作；物流公司和物流单号均由管理员确认后提交。
6. 已发货和待收货订单可查询物流公司、单号、发货时间与物流轨迹。

## 售后管理

1. 售后列表支持全部、处理中、已退款、已拒绝、已撤销状态筛选。
2. 表格展示售后单号、关联订单号、用户、售后类型、退款金额、状态与申请时间。
3. 详情展示申请原因、申请说明、退款金额、申请时间、当前状态；拒绝后展示拒绝原因和拒绝时间。
4. 仅处理中售后单显示同意和拒绝按钮。
5. 同意前二次确认；拒绝时必须填写拒绝原因。

## 后端补充

1. 新增 `GET /admin-api/trade/logistics/detail?orderId=...` 管理端物流详情接口。
2. 订单列表明确返回 `userId`；售后列表返回 `userId` 和关联 `orderSn`。
3. 保持现有订单、支付和售后状态机不变，页面操作权限以接口返回状态为准。
